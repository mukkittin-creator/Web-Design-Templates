# evraksihirbazi.com

Öğretmenler için evrak asistanı: iki soru, eksik evrak listesi, tek tıkla hazırlama.

```bash
npm install
npm run dev   # http://localhost:3000
```

| Rota | Ne |
|---|---|
| `/` | Sihirbaz (v2; v3 açılış sayfasına dönüştürülecek) |
| `/giris` | Giriş / kayıt / e-posta kodu (demo kodu: `123456`) |
| `/bakim` | Bakım modu |
| herhangi bir yanlış adres | 404 |
